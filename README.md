<h1 align="center" style="font-weight: bold;">Montador Python 💻</h1>


<h3>Clone o projeto: </h3>

```bash
https://github.com/BrendaBraganca/montador
```
<h3>Pré-requisitos:</h3>

- Arquivo .txt contendo as instruções em assembly
- Circuito simulando computador de 8 bits no Logisim Evolution

<h3>Inicializando: </h3>

*No terminal da sua IDE digite:*


```bash
   python montador.py intrucoes.txt hexa.asm
```

*No Logsim:*
1. Carregue o arquivo .asm gerado na imagem da RAM
2. Inicie o circuito
3. Confirme se o registradores armazenam os resultados esperados
